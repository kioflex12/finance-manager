# Finance Manager

Трекер расходов в Telegram: бот для мгновенной записи трат и Mini App для просмотра.
Три принципа: **практичность, удобство, скорость**.

- Написал или надиктовал боту «400 продукты» — трата записана. Можно несколько сразу: «400 продукты и 250 такси».
- Категорию подбирает LLM. Исправил категорию — для таких же трат она запоминается и дальше ставится мгновенно, без LLM.
- Комната финансов: личная или общая (по приглашению либо прямо в групповом чате).
- У комнаты есть период — календарный месяц или срок в днях. По окончании приходит сводка со сравнением с прошлым периодом; комната продлевается сама или ждёт кнопки «Начать новый период».
- Бюджет на период: остаток и сколько можно тратить в день.

## Запуск

```bash
npm install
cp .env.example .env   # заполнить BOT_TOKEN, BOT_USERNAME, WEBAPP_URL, LLM_API_KEY
npm run build
npm start
```

Сервер поднимает бота (long polling), API и отдаёт собранный миниапп с одного порта.
`WEBAPP_URL` должен быть публичным HTTPS-адресом этого сервера.

LLM и распознавание голоса подключаются по OpenAI-совместимому API, поэтому провайдер меняется в `.env` без правок кода
(Groq, OpenRouter, Gemini, локальная Ollama). В `.env.example` — бесплатный тариф Groq: один ключ на разбор трат и на голос.
При исчерпании лимита трата всё равно записывается, просто с категорией «Другое».

Без `DATABASE_URL` данные лежат во встроенной PGlite (`.data/`) — для продакшена нужен Postgres.

### Настройка бота в @BotFather

- Mini App: указать `WEBAPP_URL` как Main App — тогда работают ссылки `t.me/<bot>?startapp=...` из групп.
- Для групповых чатов выключить Group Privacy (`/setprivacy` → Disable), иначе бот не увидит сообщения «400 продукты» без обращения к нему.

### Разработка

```bash
DEV_TG_ID=1 npm run dev        # сервер; DEV_TG_ID пускает в API без Telegram
npm run dev:miniapp            # фронт с hot reload, /api проксируется на :3000
npm test                       # тесты ядра и API (на PGlite, внешние сервисы не нужны)
npm run typecheck
```

## Устройство

```
apps/server
  src/core/parse.ts    быстрый разбор «сумма + описание» без LLM
  src/core/llm.ts      разбор сложных сообщений и подбор категории (OpenAI-совместимый API)
  src/core/service.ts  комнаты, периоды, операции, правила категорий, напоминания
  src/core/text.ts     тексты сводок
  src/bot.ts           Telegram-бот и фоновые задачи (закрытие периодов, напоминания)
  src/api.ts           HTTP API миниаппа, авторизация по initData
  migrations/          SQL-миграции, применяются при старте
apps/miniapp           React-приложение (Vite)
```

Ядро не знает про Telegram: бот и API — два входа в один и тот же `service.ts`.

## Бэклог

- Мультивалютность.
- Свои категории в комнате.
